# 免费 API 再分类（诚实版）

> 核验日 2026-10-19。**不做 Web2API。**  
> 很多人注册后会发现：控制台写的是「新人赠送 / 试用」，用完就没了——那不是周期额度。

---

## 三类怎么分

| 类型 | 含义 | 能不能当长期 0 费用骨干 |
| --- | --- | --- |
| **A. 常驻价=0** | 模型定价长期写「免费」，不按 token 扣余额；通常有**并发/RPM 限速** | ✅ 可以（国内主力） |
| **B. 周期重置额度** | 每天/每月自动恢复一截配额（Neurons、RPD、月 included） | ✅ 可以（海外/溢出） |
| **C. 一次性试用** | 新人券、N 天、绑卡送 $N，过期或用完即止 | ❌ 只能短期补量 |

---

## A. 常驻价=0（你要的「长期白嫖」，但不是「每天送额度」）

| 提供商 | 说明 | 注意 |
| --- | --- | --- |
| **智谱 Flash** | 定价页明确「免费」：`GLM-4.7-Flash`、`GLM-Z1-Flash` 等 | 有并发上限；政策可能改，但目前是国内最稳的 0 费用骨干 |
| **硅基流动免费模型** | 部分模型费用 0，限速固定 | **必须实名**；免费模型名单会变，以控制台为准 |

> 这类容易被误当成「周期额度」。准确说法是：**一直免费打，但有速率天花板，不会每天 magically 补一笔 token 余额。**

---

## B. 真正「周期性」免费（会重置）

| 提供商 | 周期 | 现实情况 |
| --- | --- | --- |
| **Cloudflare Workers AI** | **日** 10,000 Neurons @ 00:00 UTC | 最干净的「每天重置」之一；大模型很快烧光 Neurons |
| **OpenRouter `:free`** | **日** 请求数（默认 50 RPD） | 模型常变、高峰 429；适合兜底不是主力 |
| **Google Gemini Free** | **日** RPD（太平洋午夜） | 常驻 Free Tier；**大陆/网络常不可用**；限额只在 AI Studio 看 |
| **Groq Free Plan** | **日** RPD/TPD 等 | 文档上是常驻 Free；**风控严，VPN/机房 IP 常登不上或 API 被拒** |
| **ModelScope 日调用** | **日**（以控制台 limits 为准） | 社区数字易过期，**以站内为准** |
| **Mistral Free mode** | **月** included | 部分大模型可能直接 0 RPM；先看控制台 Limits |

---

## C. 一次性（别当周期额度）

百炼 90 天、千帆 ~3 个月、Kimi ¥15、Cerebras $5 绑卡、豆包/混元新人包、各类「开通送资源包」……  
**用完/到期就没了**，同实名通常不能反复领。

---

## 和本项目配置的关系

- **国内长期 0 费用**：优先 **智谱 + 硅基**（类型 A），不要指望「每天送 100 万 token」。  
- **海外周期**：优先 **Cloudflare Workers AI**、**OpenRouter `:free`**；Gemini/Groq 能开再挂。  
- **Groq**：能力好，但登录/API 经常被 VPN 坑——**登不上就空着 `GROQ_API_KEY`，从 fallback 链拿掉即可。**
